什么是可信AI

00:22:13 — 00:22:59 官网回放 ↗
李萌
00:22:13

那这样我们就引入了一个可信 AI。我们觉得可信 AI 应该具备三个特质。第一个是安全稳定。那安全稳定的意思就是说我们希望用户的数据或者隐私不会被泄露。稳定，那就是我们随时可以用到这个 Agent。第二是行为可控。那 Agent 的行为应该是遵从用户的指令的。应该是接受人类的监督，合法合规的。最后一个是输出可信。那是 Agent 的输出物包括代码，包括资源配置，包括资源的编排，都是应该遵从用户的需求的，不会因为幻觉导致用户的生产资源受到任何损害。

00:23:37

00:24:24

为什么是形式化验证：从“未发现问题”到“证明不存在”

00:24:52 — 00:27:06 官网回放 ↗
李萌
00:24:53

那这里的话我就要介绍这个形式化验证这个技术。形式化验证的话，它区别于传统的测试，或者说新的大语言模型，它不是去点对点的，比如说对每个用例来进行检测。它是用数学的方法去证明某段代码，某个系统，或者说某个 Agent 它是满足用户的要求的。它是考虑了所有的输出环境，输出条件，输入条件，还有包括状态空间，然后最后去证明这个系统是否满足这个用户的要求或者规约。

00:25:29

它和传统的这个测试或者说其他的方法最大的区别就是说它可以覆盖到非常深层的缺陷，比如说并发的缺陷，比如说一些非常需要非常多的触发条件的安全的缺陷。再一个，它最重要的一点，区别于传统方式的一个特点，就是说它是可以用数学证明的方法去证明某个缺陷不存在。这是任何的质量保障的方式都无法做到的。那形式化验证技术的话， 其实也是一个老的新技术。为什么我说它老呢？

00:26:05

因为它从1970年代开始，就已经应用到航空航天的行业，用作它的软件的开发和验证。然后它是作为航空航天行业的最高级别的软件质量保障。随后的话，它也被应用到芯片行业、医疗行业，然后云服务行业、金融行业，为他们提供最高等级的保障。然后我最近之前的 18 年的话，也是在这个行业去把形式化验证推向了三个行业，同时的话，在这个商业这个行业里面，让相应的系统得到了最高等级的保障。

00:26:43

那为什么说这个形式化验证也是个新技术呢？因为在 Agent 系统的这个保障上面，形式化验证还是一个新兵。我们希望用形式化验证可以在 Agent 系统上做完善的证明，然后让我们的 Agent 系统可以达到航空等级的安全。稳定、可控、可信的保障。

行为可控：Agent Guardrail毫秒级确定性拦截

00:29:35 — 00:31:56 官网回放 ↗

00:29:36

第二是行为可控。我们刚才也说到了，我们是在 OpenAgent 的层面，是给它加了一个形式化验证的护栏。然后这个形式化验证的护栏名字叫 Agent Guardrail。然后，Agent Guardrail 的一个工作方式就是用户或者说系统管理员可以用自然语言给我们的 Agent 设定一个行为范围。比如说我永远不能去 create 一个 bucket，然后这个 bucket 可能是公共的、可读的，永远不能有这样的情况发生。

00:30:11

然后用户如果是在和 Agent 交流的过程当中，触发 Agent 去违反了这个护栏的标准，那形式化验证的这个护栏就会去给 Agent 说：“OK，你违反了这样的行为，你必须要回去。”然后 Agent 就会通过形式化验证的这么一个反馈，然后回到护栏之内，提供一个更优解，然后我在护栏之内解决同样的问题。比如在这个情况下，用户想要 create 一个 bucket，但他想把这个 bucket 给到其他人去阅读，然后他就说我是不是可以把这个 bucket 变成一个公开阅读的这么一个权限状态。

00:30:52

然后 Agent 尝试去运行这个 CLI，但是在尝试运行这个 CLI 的命令之前，形式化验证识别到这个行为是违反了用户之前的这个护栏要求，就是永远不能 create 一个新的这个公共访问的 bucket。那在这种情况下，他就直接把它拦截，然后给到 Agent 这个信息。Agent 就说：“OK，我有另外一个方式，你同样可以达成这个目的。”然后给到人工确认，人工确认之后，然后执行。

00:31:26

然后因为我们的护栏采用了形式化验证的技术，我们可以达到很高的一个准确率。其他护栏可能只有70%、60%已经算不错的了，我们的护栏可以达到99.99%的准确率。同时的话，护栏拦截的这个运行时也是非常小，可以在毫秒级之内解决。那我们希望用这个护栏，可以让用户真正得到安全的保障，稳定的保障，同时不影响用户的体验。
