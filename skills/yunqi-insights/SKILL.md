# 云栖洞察

帮助用户阅读和理解 2026 云栖大会内容。内嵌 **87 场完整讲稿、752 个主题**，包含开闭场与现场讨论；快照截至 **2026-10-13**，另有 32 场只有缺失说明。覆盖范围与数据说明见 [语料说明](references/corpus-guide.md)。

全文、目录和检索工具随 skill 提供，可由支持 skill 和本地文件读取的 AI 助手使用，**不要求特定服务商、模型或推理参数**。分析所需语料均位于本 skill 内，不依赖其他项目或数据盘。

## 可以帮助用户做什么

- **发现话题**：根据兴趣推荐演讲和主题，说明相关性、适合解决的问题及阅读顺序。
- **理解与总结**：回答内容问题，梳理一场会议或一个主题的核心观点、案例、前提与结论。
- **跨场次比较**：围绕同一问题比较不同讲者的共识、分歧和适用条件。
- **研究与提炼**：组织专题报告、分享提纲、问题清单或实践启发，并为主要结论提供出处。

例如：“找出 Agent 从 Demo 走向生产的相关演讲”“总结技术主论坛·Agentic Cloud”“比较不同专场对推理成本与可靠性的讨论”。按用户目的组织结果，无需固定输出模板；可参考 [分析与证据](references/analysis-guide.md)。

## 查找与阅读内容

先从 [场次与主题目录](data/catalog.json) 定位内容，再阅读其中 `text_file` 指向的完整讲稿。也可使用 [检索工具](scripts/corpus.py)，需 Python 3.9 或更高版本，无第三方依赖。以下命令相对于 skill 目录，数据由脚本自行定位：

```sh
python3 scripts/corpus.py list
python3 scripts/corpus.py topics --query Agent
python3 scripts/corpus.py search Harness Guardrail --match any --limit 12
python3 scripts/corpus.py read --session 230 --topic topic-002 --offset 0 --limit 20
```

- 标题、讲者和简介适合发现候选；搜索正文时主动扩展近义词、缩写及中英文拼写。检索采用字面匹配，某个拼写没有结果不代表大会没有讨论该概念。
- 搜索片段只用于定位。回答具体问题时，阅读完整命中段落及前后语境，核对指代、观点归属和限定条件。
- 总结一个主题时读完该主题；总结整场时覆盖全部主题及开闭场。依据 `has_more / next_offset` 继续分页，不把第一页或截断片段当作全文。
- `read` 保留完整段落；若工具输出被截断，减小 `--limit` 后重新读取。详细筛选方法见 [语料说明](references/corpus-guide.md#工具)。

## 表达与出处

**使用真实场次和主题名称。** 首次出现用完整名称，后文可用明确简称；编号用于辅助定位。例如“技术主论坛·Agentic Cloud [230]”，不让纯编号代替场次介绍。用户只给编号时，先从目录查出名称。

**使用已有可靠的讲者姓名。** 保留必要的主持人、画外音等角色说明；身份不明时说明待确认，不附加未经确认的花名、昵称，也不根据声音猜测姓名字形或身份对应。

**让结论可以回到原文。** 重要结论保留对应场次、主题、段落及原视频时间；展示出处时优先使用场次名称、讲者与时间。视频链接使用语料中的 `official_url`，即云栖官网场次页，不编造播放器跳转参数。例如：

> [技术主论坛·Agentic Cloud](https://yunqi.aliyun.com/2026/session?agendaId=230)｜讲者｜原视频时间范围

讲者和时间须填写实际查到的信息。区分原话、转述、编辑摘要与进一步的分析推断；画面标题和摘要不能代替讲者正文。比较数字、性能或成本时保留测试对象、口径、日期及条件；未提及某项能力不等于不支持。

## 内容来源与范围

语料基于云栖大会官网 `yunqi.aliyun.com` 的公开视频识别和整理生成，并经大模型结合视频上下文尽力纠错。这是非官方整理，转写、姓名归属和摘要仍可能有误；精确引用应结合原视频时间核对官网回放，不为使论证顺畅擅自补写或改造原文。

本 skill 提供完整文本与索引，不含视频、音频或 Slide 图片。分析时据文字证据作答，不声称直接观察过画面或听过音频。

内容反映 2026 年大会当时的演讲与观点。遇到新年份、实时产品信息或未收录资料的问题，说明当前语料范围；涉及当前事实时另行核对来源。缺少全文的场次不能当作“没有相关讨论”。
